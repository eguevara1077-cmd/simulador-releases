# Simulador para Ingreso a Universidades — instaladores

Este repositorio solo publica los instaladores del Simulador y el aviso de actualización (`actualizacion.txt`) que
leen las copias instaladas. No contiene el código ni el banco de preguntas.

- **Descargas:** sección [Releases](https://github.com/eguevara1077-cmd/simulador-releases/releases).
- **Actualizar:** el Simulador avisa dentro de la app cuando hay una versión nueva; pulsa **Actualizar**. También
  puedes ejecutar el instalador nuevo: conserva tus datos y tu licencia.
- El instalador aún no tiene firma digital: si Windows muestra «Windows protegió su PC», elige «Más información» →
  «Ejecutar de todas formas».
